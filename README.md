# 🛒 Shopeasy – Online Shopping Platform

**Shopeasy** is a modern, responsive e-commerce web application built with **React**. It offers users a seamless online shopping experience with secure authentication and dynamic product browsing.

## 🔗 Live Demo

🌐 [Visit Shopeasy](https://sunny-halva-a0af81.netlify.app)

---


## ✨ Features

* 🔐 **User Authentication**

  * Register and Login functionality using React Context API.
* 🛍️ **Product Listings**

  * Display products dynamically with category filtering.
* 🛒 **Cart System**

  * Add to cart, view cart, and simulate checkout.
* ⚙️ **Fully Responsive**

  * Mobile-friendly UI built with CSS Modules / Tailwind (if used).
* 🚀 **Deployed on Netlify**

---

## ⚙️ Tech Stack

| Technology       | Usage                         |

| Context API      | Authentication & Global State |
| CSS / Tailwind   | Styling                       |

---

## 🚀 Deployment

1. Push your code to GitHub
2. Go to [Netlify](https://netlify.com)
3. Connect your GitHub repo
4. Set build command as `npm run build`
5. Set publish directory as `build/`
6. Deploy!
